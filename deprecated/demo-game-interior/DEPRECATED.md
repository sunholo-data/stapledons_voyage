# DEPRECATED: demo-game-interior

**Status:** Deprecated (2025-12-20)

## Why Deprecated

This demo implemented AILANG-driven 3D interior navigation. This approach has been **rejected** in favor of scene-based 2D/2.5D navigation.

**Reasons for rejection:**
- Free spatial movement not needed for interior gameplay
- Game focus is conversations, not spatial exploration
- Scene-based approach better aligns with game pillars
- 3D complexity doesn't serve core gameplay goals

## Replacement

See design decision "[2025-12-20] Interior Ship Experience: Scene-Based Navigation" in [docs/vision/design-decisions.md](../../docs/vision/design-decisions.md)

New design doc: [design_docs/planned/scene-based-interior-navigation.md](../../design_docs/planned/scene-based-interior-navigation.md)

## Status

This demo may still compile if AILANG files remain, but **should not be used** as a reference for future interior features.

Consider removing in future cleanup.
